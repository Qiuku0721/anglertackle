## 1. 水体类型判定（服务端）

落点确定后，服务器按以下顺序判定**水体类型**，用于筛选鱼池：

```
第 1 步：是否属于洞穴水域？
  条件：落点上方的天空可见度 = 不可见（被方块遮蔽）
     且 水深 ≥ 4
  → WATERS = CAVE

第 2 步：检查生物群系标签
  #minecraft:is_ocean / #minecraft:is_deep_ocean  → OCEAN
  #minecraft:is_river                            → RIVER
  #minecraft:is_swamp / #minecraft:is_mangrove   → SWAMP
  其他有水体（湖泊/池塘/人工水池）                  → LAKE
```

### 1.1 海洋的离岸分级

| 分级 | 判定 | 典型鱼 |
|---|---|---|
| 海岸（Shore） | 距最近陆地 ≤ 20 格 | 沙丁鱼 |
| 近海（Nearshore） | 21–60 格 | 沙丁鱼（多）、灰鲭鲨（少） |
| **深海（Deep）** | > 60 格 **且** 水深 ≥ 8 | 灰鲭鲨、蓝鳍金枪鱼 |

> 深海判定用"离最近陆地的水平距离"实现：从落点向外做 4 次 BFS（或按 8 方向射线）检测是否触碰陆地标签方块。为性能考虑，该计算**只在落水时算一次**并缓存 5 秒。

### 1.2 水深测量

```
depth = 从落点方块向下连续统计水源方块(或含水方块)的数量，上限 12
若中途遇到非水方块 → 停止计数
depth < 2 → 判定为"浅水"，鱼池坍缩为白绿通用池
```

> - 海洋 = 大货专属（金/红）
> - 洞穴 = 单点高价值（唯一金品质，但需要发光饵 + 黑暗）

## 3. 时间与天气修正

### 3.1 时段

| 时段 | MC 时间 | 全局权重修正 | 特殊 |
|---|---|---|---|
| 清晨 | 23000–1000 | 掠食鱼 ×1.5 | 虹鳟最佳 |
| 白天 | 1000–11000 | 基准 1.0 | 沙丁鱼最佳 |
| 黄昏 | 11000–13000 | 掠食鱼 ×1.6、黄金鲤 ×1.8 | 一天中最好的时段 |
| 夜晚 | 13000–23000 | 夜行鱼 ×2.0、日行鱼 ×0.4 | 雀鳝、盲鲟最佳 |

### 3.2 天气

| 天气 | 全局权重修正 | 特殊 |
|---|---|---|
| 晴天 | 1.0 | — |
| 下雨 | 咬钩等待 ×0.75、全局权重 ×1.3 | 虹鳟 ×2.0 |
| 雷暴 | 咬钩等待 ×0.6、全局权重 ×1.5、幸运 +0.15 | **蓝鳍金枪鱼只在此出现** |

### 3.3 月相（可选，默认开启）

- 满月：夜晚全局权重 ×1.4，且解锁"月光鱼"系列（未来扩展）
- 新月：夜晚权重 ×0.8

> **【开放项8】**：月相影响要不要做？做的话多一层玄学乐趣，但玩家不容易察觉。我建议**只做满月加成 + 在图鉴里显示月相条件**。

## 4. 打窝（窝子系统）

> ⚠️ **已按你的反馈重做**：窝料从"60–90 秒的区域窝子"改成"**撒下去会散开、维持 10 分钟的增益**"，并且**分两种形态**（水面窝 / 沉底窝）。

### 4.1 两种窝料形态的世界表现

**① 水面窝（普通窝料：谷物 / 腥味肉 / 甜香果）**

```
      水面俯视图（撒下后 3 秒内散开到半径 3 格）
   ┌─────────────────────────────────┐
   │        · · · · ·                │  ← 气泡/碎屑粒子（可持续看见）
   │      · ┌───────┐ ·              │
   │      · │  窝子  │ ·              │  半径 3 格，横向散开
   │      · │  ●落点 │ ·              │  只影响 表层/中上层/中层 的鱼
   │      · └───────┘ ·              │
   │        · · · · ·                │
   └─────────────────────────────────┘
        侧视图：粒子只在水面下 1–2 格
```

**② 沉底窝（秘制配方窝）**

```
        侧视图（边下沉边散开，在目标泳层形成一片）
                水面 ═══════════════════════
                  ↓ 撒下后缓慢下沉
                ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~        ← 中层扩散带
                        ↓
            · · · · · · · · · · · · ·        ← 底层扩散带
        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓      水底
              只有这一种能影响【底层鱼】
              （黄金鲤 / 幽渊盲鲟 / 深潜型大鱼）
```

### 4.2 增益规则（已定案）

| 规则 | 值 |
|---|---|
| **持续时间** | **10 分钟**（原 60–90 秒） |
| **生效范围** | **只在同一片水域**——上岸/跨维度/换水体立即失效 |
| **同类叠加** | ❌ 不叠加，只取最高品质下限；撒新窝刷新时间 |
| 不同窝料 | ❌ 首版同时只有一种窝料生效（对应【开放项29】双槽叠加） |
| 单水域最大窝子数 | 4 个（超出最早的消失） |
| 水流影响 | 流水中的窝子持续时间 ×0.5 |
| 路亚竿 | 效果减半（时间修正折半、**品质下限不生效**） |
| 底层鱼 | **只有沉底窝（秘制配方窝）能影响到** |

### 4.3 性能优化（按你指定的"从粒子下手"）

| 项 | 优化前 | 优化后 |
|---|---|---|
| 粒子生成频率 | 每 4 tick 生成 1 个 | **每 8 tick 一次性抛 4 个**（批量低频） |
| 单 tick 粒子上限 | 无 | **最多 8 个**，超出顺延下一 tick |
| 粒子总量 | 基准 | **降低约 80%**，视觉上依然是持续冒泡 |
| 实体同步范围 | 全范围 | **只同步给 32 格内的玩家**（你的"不限数量、只限制同步范围"） |
| 远处表现 | — | 32 格外不发送实体，客户端仅靠偶尔的粒子包（可选关闭） |
| 极端情况兜底 | — | 同区块实体 > 64 时，新实体存活时间自动缩短（不拒绝生成） |

### 4.4 窝子与鱼竿的配合

```
台钓竿 + 窝料 = 数量流（快速刷白绿蓝）
路亚竿 + 好饵 = 质量流（赌紫金红）
```
这是两种玩法的经济定位差异，也是鼓励玩家**两套装备都做**的理由。

## 5. 钓点结构（世界生成）

### 5.1 自定义结构：渔夫小屋 + 码头

参考官方"溪谷钓点 - 静水湾※改为原创名"的钓鱼区设计，生成在原版河流/湖泊边：

```
        ┌────────────────────────────────────────┐
        │              渔夫小屋（5×5）             │
        │   原木墙体 + 木板屋顶 + 烟囱              │
        │   内部：床、箱子（含随机鱼饵）、工作台       │
        │   外部：晾鱼架（装饰）、灯笼              │
        └───────────────┬────────────────────────┘
                        │
        ════════════════╪════════════════════   ← 木码头（延伸入水 5–8 格）
                        │
        ┌───────────────┴────────────────────────┐
        │  码头尽头：钓鱼椅（可坐）+ 鱼桶（装饰）    │
        │  水面下：3×3 的深水坑（保证足够水深）      │
        └────────────────────────────────────────┘
                     ↑ 老柯 NPC 生成点（小屋前）
```

| 项 | 值 |
|---|---|
| 结构 ID | `anglertackle:fisherman_hut` |
| 生成群系 | `#minecraft:is_river`、`#minecraft:is_swamp`、湖泊岸边 |
| 生成间距 | 平均每 40 个区块 1 个（稀疏，保证"发现"的惊喜感） |
| 战利品 | 箱子里：随机鱼饵 ×4–12、鱼线 ×1、鱼币 ×20–80、稀有概率 5% 出拟饵 |
| 变体 | 海洋版（木栈桥 + 小船，生成在海岸）—— M8 扩展 |

### 5.2 NPC 老柯

| 属性 | 值 |
|---|---|
| 实体类型 | `anglertackle:fisherman`（自定义生物） |
| 外观 | 老人形，戴草帽、穿背带裤（MC 村民风格改造） |
| 生成 | 渔夫小屋结构内 1 个（结构生成时同时生成） |
| 行为 | 站在码头附近；玩家靠近 3 格内可交互；夜晚回到小屋 |
| 交互 | 右键 → 对话 GUI（学钓鱼 / 考核 / 商店 / 任务 / 排行榜） |
| 保护 | 不可被玩家伤害（受击时闪现并传送回小屋） |
| 复活 | 被 `/kill` 或意外移除后，若结构仍在，30 秒后在原位重生 |

> 为什么不做成村民职业？你选了"自定义 NPC"，理由是：官方老柯有**台词、任务链、考核**三重身份，村民交易界面塞不下。
> **【开放项9】**：要不要**同时**加一个"鱼商"村民职业（只做买卖，方便在基地附近交易）？我建议加，成本低、体验好。

## 6. 实体鱼（可选系统）【开放项10】

两种方案，影响性能与沉浸感：

| 方案 | 说明 | 性能 | 沉浸感 |
|---|---|---|---|
| **A. 纯数据水点（推荐首版）** | 水里不生真实鱼实体，咬钩完全由公式决定；窝子/涟漪用粒子表现 | 几乎零开销 | 中（看不到鱼，但钓鱼过程有反馈） |
| **B. 生成实体鱼群** | 在合适水域生成 3–8 条小鱼实体巡游，咬钩优先选附近实体鱼 | 需要 AI + 寻路，每个区块上限 3 条 | 高（能看到鱼、能用桶抓鱼） |
| **C. 混合** | 默认 A；配置项可开 B（`gameplay.spawnFishEntities=true`） | 可调 | 可调 |

我建议 **C**：默认 A 保证兼容性和性能（整合包友好），但保留 B 作为可选，并且 B 模式下"用桶捞鱼"能获得鱼饵（蚯蚓/小鱼）——形成一个"捞饵 → 钓鱼"的小循环。

## 7. 性能与兼容性注意

| 项 | 措施 |
|---|---|
| 鱼群实体上限 | 每区块 ≤ 3，全局 ≤ 200（可配置） |
| 窝子粒子 | 每窝每 4 tick 1 个粒子，最多 4 窝 → 上限很低 |
| 水深/离岸计算 | 只在落水时算一次并缓存 |
| 多人同步 | 抛投实体、咬钩事件、张力状态通过自定义网络包同步（详见 06 文档） |
| 与其他钓鱼模组共存 | 不改原版 `FishingHook` 行为；只新增自己的实体与物品 |
| 与区块加载模组 | 不需要额外兼容（不依赖区块常加载） |
| 服务端仅安装 | 完全支持（所有判定在服务端，客户端只装 UI 与渲染） |
