| 项 | 原方案（危险） | 现方案（安全） |
|---|---|---|

**为什么必须换**："Delta Force / 三角洲行动"是腾讯天美工作室群的注册商标。CurseForge 与 Modrinth 都会响应版权方的下架请求（DMCA），**项目名或描述里带商标词会被直接下架**，而且账号可能被标记。这类下架在 MC 社区发生过多次。

### 什么是安全的、什么是危险的

| ✅ 安全（玩法机制不受版权保护） | ❌ 危险（会招来下架） |
|---|---|
| 钓鱼小游戏机制（浮漂/张力/收线） | 名字里出现 "Delta Force / 三角洲" |
| 装备分层改装系统 | 使用官方 Logo、UI 截图、宣传图 |
| 稀有度分级、图鉴、认证晋升 | 复刻官方角色（老柯、德穆兰、旅人）的形象与名字 |
| 数值结构（耐久/价格/概率） | 直接提取官方音效、贴图、模型文件 |
| "灵感来自现代战术射击游戏的钓鱼玩法" 这类**不点名的**描述 | 帖子里写"这是垂纶玩法的复刻"作为卖点 |

> **NPC 命名也要改**：`05-世界与钓点.md` 里的 NPC「老柯」需要换个原创名字。我在本文档 §6 给出候选，你挑一个（或自己起）。

## 2. 平台选择与策略

| 平台 | 用户量 | 审核 | 对开发者 | 建议 |
|---|---|---|---|---|
| **CurseForge** | 最大（尤其整合包作者） | 人工审核，要求 LICENSE 与正确元数据 | 支持 Gradle 自动上传插件 | ✅ **必发**，主要流量来源 |
| **Modrinth** | 增长快，年轻用户多 | 较严，会问素材来源与许可证 | API 友好，自动化最好 | ✅ **必发**，技术社区口碑好 |
| MCBBS / 国内论坛 | 国内玩家 | 无审核 | 手动上传 | ⏳ 可选，需要额外写中文宣传文案 |
| 自己的 GitHub Releases | 最少 | 无 | 完全自由 | ✅ 建议做，作为"权威发布源"与问题追踪处 |

**发布流程（先做东西，这份是给 M7 之后用的）**：

```
M7 完成 → 打第一个正式版 jar
   ↓
① 注册 CurseForge + Modrinth 账号（只能你自己注册，我代不了）
   ↓
② 建项目页：图标（400×400 PNG）、封面图、描述（中英双语）、分类标签
   ↓
③ 上传 jar → 填版本号、支持的 MC 版本（1.21.1）、加载器（NeoForge）
   ↓
④ 后续版本：我在构建脚本里配好自动化，你只需填一次 API Token
   → 以后 `./gradlew publishMods` 一条命令同时发两个平台
```

```
THE SOFTWARE IS PROVIDED "AS IS", WITHOUT WARRANTY OF ANY KIND, ...
```

| 选项 | 别人能否放进整合包 | 别人能否二次开发 | 你需要做什么 |
|---|---|---|---|
| **MIT**（建议） | ✅ 可以，无需问你 | ✅ 可以，需保留你的署名 | 在 jar 与仓库里放 LICENSE 文件 |
| Apache-2.0 | ✅ 可以 | ✅ 可以（含专利授权） | 同上 + NOTICE 文件 |
| LGPL-3.0 | ✅ 可以 | ✅ 可以，但改过的部分必须开源 | 代码要分区清晰 |
| ARR（保留所有权利） | ⚠️ 需要你授权，很多整合包会跳过 | ❌ 不可以 | 无 |

> ⚠️ **注意区分三种许可证**：
> - **代码**：MIT（上面这个）
> - **素材**：CC0 / CC-BY（由原作者决定，你的 MIT 不能覆盖别人的 CC-BY 素材）
> - **美术成品**：你自己改的像素图，可以跟着 MIT 一起放出去

## 4. 素材合规（上架审核最容易卡的地方）

CurseForge 和 Modrinth 都会（尤其 Modrinth）检查素材来源。我们的应对：

| 措施 | 说明 |
|---|---|
| **只用 CC0 / CC-BY** | 绝不用 CC-BY-SA / GPL / NC（非商业）素材——会污染整个项目的授权 |
| **`CREDITS.txt` 随 jar 分发** | 放在 `src/main/resources/CREDITS.txt`，格式：素材名 + 作者 + 来源 URL + 许可证 |
| **`docs/07-美术与素材.md` 附录** 维护完整清单 | 每引入一个素材就追加一行，发布时直接抄进项目页 |
| **原版音效可以直接用** | `minecraft:entity.fishing_bobber.splash` 等属于 MC 本体，所有模组都能引用，不算侵权 |
| **AI 生成素材** | Modrinth 2025 年起要求标注 AI 生成内容。如果我用脚本生成/改造贴图，会在 CREDITS 里注明"程序化生成" |
| **禁止提取游戏文件** | 绝不从《三角洲行动》或其他商业游戏里提取任何贴图/音效/模型 |

**项目页描述模板**（中英双语，避开商标）：

```markdown
# 垂纶 · Angler's Tackle

一个以"手感优先"为核心的钓鱼模组：抛投物理、浮漂读秒、鱼线张力对抗、
六槽渔具改装、鱼类图鉴、认证晋升与自定义货币经济。

A fishing mod built around feel: physical casting, float-reading, line-tension
fighting, six-slot tackle customization, a fish codex, certificates and a
custom currency.

## 特色 / Features
- 台钓竿看浮漂三段预告，路亚竿靠张力对抗（白→黄→红→断线）
- 六槽改装：竿身 / 鱼线 / 渔轮 / 鱼钩 / 拟饵 / 浮漂
- 窝料抬品质下限，饵料定品质下限——大饵钓不到小鱼
- 10 种鱼（首版），含 2 种 Boss 级巨物
- 图鉴记录最大/最小尺寸与重量，5 档尺寸评级
- 自定义货币、钓鱼商店、NPC 任务与认证考核
- 不与原版钓鱼冲突，可服务端单独安装

## 依赖 / Requirements
- Minecraft 1.21.1
- NeoForge 21.1.x
- 无强制前置模组
```
