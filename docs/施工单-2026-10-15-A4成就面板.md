## §1 最小可行形状（**别另起设计**，照下面抄）

这个仓库每个功能都是同一套四件：**载荷 → 客户端缓存 → 界面 → 注册**。成就照抄即可：

| 件 | 模板（现成、已核实） | 你要写的 |
|---|---|---|
| 客户端缓存 | `client/ClientQuests.java`（**44 行**，含 `accept/synced/latest/clear`）| `client/ClientAchievements.java`（照抄改名，`clear()` 的注释理由也照抄）|
| 载荷（S2C）| `network/QuestPayload.java`（102 行，`rows` 用 `FIELD_SEP` 拼字符串）+ `network/GuidePayload.java`（83 行，**界面构造器直接吃 payload**）| `network/AchievementPayload.java`（`List<String> rows` + `int total`）|
| 界面 | `client/screen/UiLayout.java`（179 行）+ `TextWidget.java`（83 行）是现成helper；**版面 470×224** | `client/screen/AchievementScreen.java`（**最小版**：一条一行"名字 ✓/✗ + 25币/20经验"）|
| 注册/发送 | 见 §2 | 3 处改动 + 1 个发送方法 |

**省一个载荷的关键**：**不要写 C2S 请求载荷**。`/atl ach` 这条指令**本身就是请求** ——
服务端收到就直接推一份 S2C 快照，客户端收到就开界面（`handleQuests` 就是这么做的：
`mc.setScreen(new QuestScreen())`）。委托之所以有请求载荷，是因为它还有右键老柯等多个入口。

## §2 三处注册与发送（行号是 2026-10-15 晚实测）

1. **客户端注册 + 处理器**：`client/ClientPayloadHandlers.java`
   - 第 97~98 行那一组 `registrar.playToClient(...)` 后面加一组：
     `registrar.playToClient(AchievementPayload.TYPE, AchievementPayload.STREAM_CODEC, ClientPayloadHandlers::handleAchievements);`
   - 第 108~118 行的 `handleQuests` 照抄一份 `handleAchievements`：
     `context.enqueueWork(() -> { ClientAchievements.accept(payload); Minecraft mc = Minecraft.getInstance();
      if (mc.screen instanceof AchievementScreen as) { as.refresh(); } else { mc.setScreen(new AchievementScreen()); } });`
     ⚠ **先落缓存再开界面**，且"已经开着 ⇒ 就地 refresh"（否则戴/领时界面闪一下）。
2. **服务端发送**：`network/ModNetwork.java` 第 120~145 行的 `syncQuests` 照抄一个
   `public static void syncAchievements(ServerPlayer player)`：遍历 `AchievementDef.all()`，
   每行拼 `id + FIELD_SEP + (unlocked?"1":"0") + FIELD_SEP + tier + FIELD_SEP + coins + FIELD_SEP + xp`
   （`unlocked` 从 `PlayerData.getAchievements(player).has(id)` 读），最后 `sendTo(player, new AchievementPayload(rows, AchievementDef.count()))`。
   **S2C 载荷不需要在 `register(...)` 里 `playToServer`**（那只给 C2S 用）。
3. **断线清缓存**：`event/CoinSyncEvents.java` 第 73 行 `ClientQuests.clear()` 旁边加 `ClientAchievements.clear()`
   （理由同注释：否则下一个存档会先闪一眼上个存档的成就）。
