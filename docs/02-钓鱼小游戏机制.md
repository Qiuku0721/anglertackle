## 1. 总状态机

钓鱼行为由一个**服务端权威**的状态机驱动，每个玩家同时只能处于一个钓鱼会话中。

```
        ┌────────┐
        │  IDLE  │  空手 / 未持竿
        └───┬────┘
            │ 手持钓竿 + 右键
            ▼
      ┌───────────┐  松开右键（蓄力<0.15s→取消）
      │  CHARGING │──────────────────────────────┐
      │  蓄力中    │                              │
      └─────┬─────┘                              │
            │ 松开右键                            │
            ▼                                     │
      ┌───────────┐  落点无效（陆地/无水体/太浅）    │
      │  CASTING  │──────────────────────────────┤
      │  抛投飞行  │                              │
      └─────┬─────┘                              │
            │ 浮漂/拟饵入水                        │
            ▼                                     │
   ┌─────────────────┐  超时未咬钩 / 玩家移动超过 3 格 │
   │    WAITING      │──────────────────────────────┤
   │  等待咬钩        │                              │
   │  （台钓：浮漂静置）│                             │
   │  （路亚：可收线）  │                             │
   └────────┬────────┘                              │
            │ 咬钩触发（服务器判定）                    │
            ▼                                      │
      ┌───────────┐  未在窗口内提竿（错过）           │
      │ HOOK_WINDOW│─────────────────────────────┤
      │ 提竿窗口   │  ★ 进入此状态瞬间已扣耐久       │
      └─────┬─────┘                              │
            │ 玩家提竿成功（窗口内右键/左键）          │
            ▼                                     │
      ┌───────────┐  张力满 → 切线                  │
      │  FIGHT    │─────────────────────────────┤
      │  张力对抗  │  鱼体力先归零 → 逃脱（罕见）      │
      └─────┬─────┘                              │
            │ 鱼体力 = 0 且 距离 ≤ 近岸圈            │
            ▼                                     │
      ┌───────────┐                              │
      │  LANDING  │  结算动画（0.8–2.5s）           │
      └─────┬─────┘                              │
            │                                     │
            ▼                                     ▼
      ┌────────────────────────────────────────────┐
      │  RESULT（成功上鱼 / 逃脱 / 断线 / 取消）      │
      │  → 结算、图鉴、经验、播报 → 回到 IDLE         │
      └────────────────────────────────────────────┘
```

**关键设计**：`HOOK_WINDOW` 是"咬钩"这一刻，**你的规则在这里生效**——无论玩家最后钓上来、切线、还是错过提竿，只要鱼咬了钩，耐久就已经扣掉了。

## 2. 阶段一：蓄力与抛投（CASTING）

### 2.1 蓄力

- 手持钓竿长按右键进入 `CHARGING`。
- 蓄力值 `power` 从 0 线性增长到 1.0，耗时 `chargeTime`。
  - 台钓竿：`chargeTime = 1.2s`（抛得近、精度高）
  - 路亚竿：`chargeTime = 1.6s`（抛得远、需要控制）
- HUD 显示蓄力条，并在条上叠加**两段颜色标记**：绿区（最佳力度，落点误差最小）、黄区（可接受）、红区（过力，落点随机偏移大）。
- **过力惩罚**：`power > 1.0` 后继续按住不会更强，但如果松开时 `power` 在红区，落点误差 ±3 格；在绿区误差 ±0.5 格。

### 2.2 抛投物理

不用真实弹道模拟，用**参数化抛物线**（更好调、更可预测）：

```
抛投初速      v0     = 1.2 + 1.6 * power                (格/tick, 约 24–56 格/s)
发射仰角      θ      = 32°（固定，保证抛物线好看）
水平射程      range  = v0² * sin(2θ) / g    , g = 0.05 格/tick²
实际落点      = 玩家朝向 + 角度随机偏移(误差) + range
```

`range` 数值参考（可直接调）：

| power | 台钓竿射程 | 路亚竿射程 |
|---|---|---|
| 0.25 | 7 格 | 9 格 |
| 0.50 | 16 格 | 20 格 |
| 0.75 | 26 格 | 32 格 |
| 1.00 | 35 格 | 42 格 |

**鱼线长度上限**（你选的"鱼线独立属性"）：射程会被 `min(range, 鱼线长度)` 硬限制，超出的蓄力直接浪费——这是低品质线"钓不到远水"的机制来源。

| 鱼线品质 | 线长上限 | 说明 |
|---|---|---|
| 低级（白/绿） | 30 格 | 浅水近岸够用 |
| 中级（蓝/紫） | 40 格 | 能到深水区边缘 |
| 高级（金） | 55 格 | 基本无限制 |
| 顶级（红） | 70 格 | 纯性能 |

### 2.3 落点判定

浮漂/拟饵的落点是一个**真实实体**（`BobberEntity`），飞行过程逐 tick 插值，视觉上玩家能看到抛物线。落水时判定：

| 落点情况 | 结果 |
|---|---|
| 落在地面 / 非水源方块 | 立即回收，`RESULT(落点无效)`，**不扣耐久** |
| 落在水源方块但水深 < 2 格 | 可钓，但鱼种池坍缩为"浅水鱼"（多为白绿） |
| 落在水源方块且水深 ≥ 2 格 | 正常 |
| 落在流动水 | 可钓，但咬钩时间 ×1.5（水流冲走了气味） |
| 落在水面上方 1 格内但被方块遮挡 | 判定为"卡线"，直接回收 |

> 水深定义为：从落点向下连续水源方块的数量（上限统计 8 格）。

## 3. 阶段二：等待与咬钩（WAITING / HOOK_WINDOW）

### 3.1 鱼种池计算（服务器）

咬钩时，服务器按以下顺序计算候选鱼池，先做"资格筛选"，再做"权重抽取"：

```
第 1 步 · 硬性资格（不满足直接排除）
  ├─ 水域类型匹配      （海洋/河流/沼泽/洞穴水域）
  ├─ 维度匹配          （主世界/下界/末地）
  ├─ 生物群系匹配      （寒带/温带/热带/蘑菇岛…）
  ├─ 泳层匹配          （路亚：拟饵泳层 ∈ 鱼的泳层；台钓：忽略）
  ├─ 水深要求          （鱼.minDepth ≤ 实际水深）
  ├─ 尺寸要求          （鱼.maxSize ≤ 鱼竿承重）
  ├─ 认证要求          （鱼.requiredCert ≤ 玩家认证等级）
  └─ 特殊条件          （部分鱼要求夜晚/雨天/雷暴/满月）

第 2 步 · 权重计算

  最终权重 W = 基础权重
             × 鱼饵吸引系数      (0.5 ~ 3.0)
             × 窝料吸引系数      (1.0 ~ 2.5，仅台钓/静水)
             × 时间系数          (0.3 ~ 3.0)
             × 天气系数          (1.0 ~ 2.5)
             × 深度系数          (1.0 ~ 1.8，随水深接近鱼的最适深度上升)
             × 竿类型系数        (1.0 / 1.5)
             × 玩家幸运系数      (1.0 ~ 1.6，附魔/药水/认证等级)

第 3 步 · 抽取
  按权重做加权随机；若池子为空（例如认证不够+饵不对+水深不够），
  回退到"白绿通用池"（保证任何情况下都能钓到点什么，绝不空手而归）
```

> ⚠️ **已按你的反馈重构**：**稀有度惩罚不再放在权重里**。你的设计是"**打窝料负责抬品质下限、饵料负责筛选**"，所以品质下限由"**窝料 + 饵料**"共同决定（见下节 §3.1.1），而不是靠一个隐藏的稀有度惩罚系数。
> 这样玩家的心智模型变成一句话就能说清：**"想钓好鱼 → 买好窝料把下限抬起来；想避开小鱼 → 换大饵把小鱼筛掉。"**

### 3.2 咬钩等待时间（台钓竿）

> ⚠️ **已按你的反馈调整**：原设计基础等待 3–15s、硬上限 45s，太长。玩家扛不住半分钟以上的干等，**新基线上限压到 20s**。

```
基础等待 t_base ∈ [2.0s, 8.0s]，均匀随机          ← 原 3–15s，整体缩短约 45%
修正后    t = t_base × 流动水修正(1.3) × 窝料修正(0.45~1.0) × 鱼稀有度修正(0.8~1.5)
硬上限    20s（原 45s）
```

| 目标鱼 | 无窝料平均等待 | 打窝后平均等待 |
|---|---|---|
| 白 | 3.5s | 2.0s |
| 绿 | 4.5s | 2.4s |
| 蓝 | 6.0s | 3.0s |
| 紫 | 8.0s | 3.8s |
| 金 | 10.0s | 4.5s |
| 红 | 12.0s | 5.5s |

**为什么"打窝缩短时间"要比原设计更强**：你把打窝定位成"缩短上鱼时间 + 吸引高级鱼"的核心手段，所以窝料修正从原来的 `0.6~1.0` 改成 `0.45~1.0`——**打窝前后体感差异要一眼可辨**，否则玩家不会愿意花鱼币买窝料。

其他规则：
- 玩家在等待期间**移动超过 3 格**或**切换物品**→ 立即取消（收线）。
- 等待期间浮漂必须有持续反馈（见 3.3），**绝对不能是纯干等**。
- **路亚竿没有等待**（见 3.4），全程主动收线找鱼——这也是你缩短台钓等待的另一个理由：想快就玩路亚。

### 3.3 台钓竿：浮漂三段预告动画（★原创强化，官方没有）

这是提升"技巧感"的关键设计。浮漂在真正下沉前，会经历三段可读的动画：

| 阶段 | 时长 | 浮漂表现 | 音效 | 玩家该做什么 |
|---|---|---|---|---|
| **① 探饵** | 0.3–1.2s | 浮漂轻微上下抖动（±0.5 像素） | 细微"啵"声 | 别动！ |
| **② 试探** | 0.3–0.8s | 浮漂下沉 1/3 后回弹，可能来回 1–3 次 | 水花声渐强 | 别动！这是小鱼在试 |
| **③ 吞钩** | **提竿窗口**（0.35–0.75s） | 浮漂**完全沉入水面下**，水面出现涟漪粒子 | 沉闷的"咕咚"+ 水面爆开粒子 | **立刻提竿！** |

**错过窗口**：浮漂重新浮起，本次咬钩作废，但**耐久已扣**（你的规则），重新进入 `WAITING`（等待时间 ×0.6，因为鱼还在附近）。

**窗口时长公式**（越高级的鱼窗口越短，增加紧张感）：

```
提竿窗口 = 0.75s - 0.06s × 稀有度等级(0=白…5=红)
              + 0.10s × 鱼竿品质加成(木0 铁1 金0 钻2 合金3)
              + 0.15s × 认证等级(0~3)
下限 0.30s，上限 1.00s
```

### 3.4 路亚竿：主动引诱（无等待）

路亚竿**不存在"抛下去干等"**，玩家通过收线主动找鱼：

- 落到水面后，玩家可按住"收线键"（默认右键持续 / 或 `R` 键【开放项1】）收线。
- 拟饵有**泳层**属性，通过收线速度控制：

| 收线状态 | 拟饵泳层 | 说明 |
|---|---|---|
| 不动 | 停止下沉，停在当前层 | 静止时掠食鱼不感兴趣，但可能被好奇鱼咬 |
| 慢收 | 下沉（表层→中层→底层） | 每 tick 下沉 0.04 格 |
| 快收 | 上浮（底层→中层→表层） | 每 tick 上浮 0.06 格 |
| 抽动（点按） | 原地抖动 | 触发"掠食反应"，瞬间提高 2 倍咬钩率，持续 1s |

- 咬钩触发条件：每一 tick 判定 `P(咬钩) = 鱼群密度 × 拟饵匹配度 × 泳层匹配度 × 抽动加成`。
- 咬钩前 0.25s 有预告：**水面出现一条追饵的水痕（粒子）**，给玩家反应时间。
- 咬钩瞬间：**鱼线绷紧**（线的视觉由松弛变直线）+ 音效"啪"，进入 `HOOK_WINDOW`，玩家必须在窗口内提竿。

## 4. 阶段三：张力对抗（FIGHT）★ 最核心的手感

### 4.1 玩家输入

| 按键 | 行为 | 对张力的影响 | 对距离/体力的影响 |
|---|---|---|---|
| **左键按住** | 收线 | 张力上涨（受控杆方向修正） | 拉近；鱼体力下降 |
| **松开左键** | 放线 | 每 tick `-1.6` 张力 | 鱼跑远 |
| **A / D** | 控杆方向（正拉 / 反拉） | 见下表 | 影响体力削减效率 |
| 不按 | 垂直（中立） | 基准 | 基准 |

**控杆三方向**（完整数值见 `14-鱼的手感档案.md` §1.1）：

| 关系 | 鱼体力削减 | 张力上涨 | 定位 |
|---|---|---|---|
| **正拉**（顺着鱼） | ×0.65 | ×0.50 | 安全但慢 |
| **中立**（垂直/不按） | ×1.00 | ×1.00 | 不做就不错 |
| **反拉**（逆着鱼） | ×1.50 | ×1.40 | 快但危险 |

> **左键拦截的安全性**（回应你的"原版机制冲突"担忧）：只在**同时满足**"手持本模组钓竿 + 存在活跃会话 + 状态为提竿窗口或对抗中"时才吞掉左键，其他任何情况放行，绝不影响挖掘/攻击。实现见 `09-原版冲突与渲染优化.md` §2 第 3 条。

**错过提竿的后果**（已按你的定案修改）：

```
提竿窗口 = 2.0 秒
  ↓ 2 秒内没按左键
鱼逃离 → 扣【鱼线耐久】+ 扣【饵料】→ 不扣鱼竿耐久
  ↓
会话直接结束（不回到等待状态）
```

> 与"咬钩即扣竿耐久"不冲突：**咬了钩就扣竿耐久（无论成败）**，
> 但"没提竿导致鱼跑掉"这一次**不再额外扣竿耐久**——竿的损耗只发生一次。

### 4.2 张力模型

> ⚠️ **已按你的反馈调整**：张力反馈**以鱼线视觉为主**，HUD 张力条只做辅助，不搞花哨效果。

**张力 → 鱼线视觉映射**（这是玩家唯一必须看懂的东西）：

| 张力 | 鱼线颜色 | 鱼线形态 | 音效 | 玩家感知 |
|---|---|---|---|---|
| 0 – 55 | **白**（`#FFFFFF` → `#E4E4E4`） | 略松弛，轻微下垂弧度 | 无 / 极轻 | 安全，放心收 |
| 55 – 82 | **黄**（`#F0C93B`，随张力加深） | 绷直 | 线的"嗡"声（音量随张力升） | 注意，稳一点 |
| 82 – 98 | **红**（`#E85C5C` → `#C62828`） | 绷到极致，轻微抖动 | "吱吱"摩擦声 | 快断了！放线！ |
| ≥ 98 | **深红闪烁**（`#5C1010` ↔ `#FF5555`，2 Hz） | 抖动剧烈 | 高频"吱嘎" | 下一瞬间就断 |
| 断线 | — | 线瞬间消失 + 水花粒子 | 断裂"啪" | 结束了 |

辅助 HUD（可选，默认开启但极简）：屏幕下方一条 **260×8 px** 的细条，用白/黄/红三段底色 + 一根当前位置竖线。**没有暗角、没有屏幕震动、没有呼吸闪烁、没有额外文字**（除非玩家在设置里主动打开"详细提示"）。

```
张力 T ∈ [0, 100]
  0 – 55  白区（优）：安全，收线效率 100%
 55 – 82  黄区（中）：安全，收线效率 60%，鱼体力消耗 ×1.2
 82 – 100 红区（危）：计时器启动，累计停留 > breakTime → 断线
 >100     立即断线

每 tick 更新：
  ΔT = 玩家收线(+0.9) 或 放线(-1.6) 或 僵持(-0.35)
     + 鱼的拉力贡献：
         常态         +0.15 × 鱼力量系数
         冲刺中       +0.95 × 鱼力量系数        ← 必须放线
         挣扎方向正确  -0.50
         挣扎方向错误  +0.35                    ← 惩罚，让变向有意义
     × 鱼线张力衰减系数（线品质越好，涨得越慢）
     - 卷线器/绕线轮加成（若装了该配件）

  T = clamp(T, 0, 110)
```

**鱼力量系数**参考值：

| 鱼稀有度 | 力量系数 | 冲刺时长 | 冲刺间隔 |
|---|---|---|---|
| 白 | 0.7 | 0.8s | 4.5s |
| 绿 | 0.9 | 1.0s | 4.0s |
| 蓝 | 1.1 | 1.2s | 3.5s |
| 紫 | 1.4 | 1.5s | 3.0s |
| 金 | 1.8 | 1.8s | 2.5s |
| 红 | 2.4 | 2.2s | 2.0s |
| **Boss 大鱼** | ×1.6 于同稀有度 | +0.5s | −0.8s |

### 4.3 鱼的体力与挣扎

```
鱼体力 S ∈ [0, S_max]
  S_max = 100 × 鱼稀有度成长 × (1 + 0.12 × (重量 - 该鱼平均重量)/平均重量)

每 tick：
  收线时       S -= 0.55 × 收线效率     ← 拉得越狠，鱼越累（黄区也有收益）
  鱼冲刺时     S -= 0.10                ← 冲刺很耗鱼体力，撑过去就赢
  停滞不动     S += 0.02                ← 鱼会缓慢回气，不能一直摸鱼

  挣扎方向：每 1.2–3.0s 随机切换一次（左 / 右 / 直冲）
    玩家按对方向 → 额外 S -= 0.35/tick
    玩家按错方向 → 张力 +0.35/tick
    Boss 鱼：切换更频繁（0.8–1.8s），且有 15% 概率"假动作"（预告一个方向实际反方向）
```

### 4.4 断线与红区计时

```
breakTime（红区可停留时长）=
      2.2s
    + 0.6s × 鱼竿品质(0~4)
    + 0.8s × 鱼线品质(0~4)
    + 0.3s × 认证等级(0~3)
    - 0.35s × 鱼稀有度(0~5)
    - 1.0s  （若为 Boss 大鱼）
    clamp 到 [0.6s, 5.0s]
```

- 红区时：**鱼线颜色转红并发出"吱吱"摩擦音**（唯一的警示手段，不做画面暗角/震动）；HUD 细条同步转红。
- **张力降到黄区/白区，计时器以 2 倍速度回退**（给玩家救回来的机会，不做一票否决）。

### 4.5 距离与逃生

```
玩家 - 鱼 距离 D
  初始 D0 = 抛投落点距离（例如 25 格）
  近岸圈 = 6 格 + 1 格 × 认证等级      ← 若玩家站在水里，改为"到玩家的距离 ≤ 3 格"

  D 每 tick：收线 -0.06，放线 +0.10，僵持 +0.02
  D 达到 D_max = D0 × 1.8 → 鱼逃出鱼线范围，本次结束（逃脱）

上鱼成功条件：S ≤ 0 且 D ≤ 近岸圈
  → 进入 LANDING，播放 0.8–2.5s 收鱼动画（鱼越大越长）
```

### 4.6 台钓竿的对抗（简化版）

台钓竿不用完整张力系统（否则两种竿没区别），但也不能点了提竿就直接上鱼：

- 提竿成功后进入 **"遛鱼"** 简化对抗：只需在**3 次**张力提示中做对选择（收线/放线），每次窗口 1.0s。
- 3 次全对 → 直接上鱼；错 1 次 → 张力 +30；错 2 次 → 断线。**最低级鱼（白/绿）跳过遛鱼，直接上鱼**（照顾休闲玩家和前期体验）。
- 台钓竿的优势：**数量多、门槛低、能吃窝料加成**；路亚竿的优势：**能钓大货、能主动找鱼、红品质鱼只能路亚**。

## 5. 阶段四：结算（RESULT）

### 5.1 尺寸与重量随机

每条鱼在咬钩时（而非上鱼时）就由服务器生成好尺寸数据，防止玩家通过重连刷数值：

```
体长 L = 该鱼最小长度 + (最大长度 - 最小长度) × 随机^偏斜
重量 W = k × L^3 × 体态系数 × (1 ± 0.12 随机扰动)     ← 立方关系，让"大个体"很稀有
```

**尺寸评级**（用于图鉴与评价）：

| 评级 | 条件 | 颜色 |
|---|---|---|
| 幼体 | L < 最小长度 + 15%(范围) | 灰 |
| 普通 | 15%–55% | 白 |
| 优质 | 55%–85% | 绿 |
| 极品 | 85%–97% | 蓝 |
| **纪录级** | ≥ 97% | 金 + 全服播报 |

> 这个"同种鱼也有追求"的设计，是为了让 10 种鱼也能玩很久——每种鱼有 5 个档次的个体记录要刷。

### 5.2 图鉴更新

- 首次钓到某鱼 → 图鉴点亮 + 图鉴完成度 +1（有专门的完成度进度条与阶段性奖励）
- 后续钓到 → 刷新该鱼的**最大/最小长度、最大/最小重量、最高稀有度个体、尺寸评级**
- **图鉴独立于鱼获**：鱼卖掉/送人/吃掉都不影响图鉴（照搬官方设定）
- 图鉴数据存服务器玩家数据（`Attachment`），跨存档跟随玩家【开放项2】

### 5.3 鱼币收益

```
收益 = 鱼基础价 × 稀有度乘数 × 重量系数 × 尺寸评级加成 × 商店议价等级
  基础价：白 3 / 绿 8 / 蓝 20 / 紫 55 / 金 150 / 红 500 鱼币
  重量系数 = clamp(W / 该鱼平均重量, 0.6, 2.5)
  尺寸评级加成：幼0.7 / 普通1.0 / 优质1.25 / 极品1.6 / 纪录2.5
```

## 6. 耐久系统（按你自定义的规则）

### 6.1 鱼线耐久

- **每次鱼咬钩固定 −1 点**，无论最终钓上来 / 切线 / 错过提竿。
- 断线额外 −5 点。
- 鱼线耐久按品质：

| 鱼线品质 | 耐久 |
|---|---|
| 低级（白/绿） | **50** |
| 中级（蓝/紫） | **40** |
| 高级（金） | **30** |
| 顶级（红） | **20** |

> ⚠️ **【开放项3】需要你确认**：你原话是"低级鱼线 50 到 40 耐，中级（紫，金品质）40 到 30 耐，高级（红）20 耐"。我理解为"耐久随品质递减：白绿 50 / 蓝紫 40 / 金 30 / 红 20"，即**越高级的线越娇贵但性能更强**。如果你的本意是别的（例如 50–40 指一个范围），告诉我我改。

### 6.2 鱼竿耐久

| 鱼竿品质 | 最大耐久 | 说明 |
|---|---|---|
| 木竿 | **2000** | 你定的起步值 |
| 铁竿 | 3500 | |
| 金竿 | 2500 | 易弯但韧，性能特殊（咬钩窗口更长） |
| 钻石竿 | 5000 | |

**每次咬钩对鱼竿的损耗**：

```
鱼竿耐久损耗 = 基础损耗(按稀有度) × 鱼竿材质系数 × Boss倍率(1.6) × 尺寸系数
  基础损耗：白 2 / 绿 4 / 蓝 7 / 紫 12 / 金 20 / 红 30      ← 越高级的鱼损耗越大（你的规则）
  鱼竿材质系数：木 1.0 / 铁 0.85 / 金 0.9 / 钻石 0.7 / 下界合金 0.5
  尺寸系数 = 1 + (L - 该鱼平均长度) / 该鱼平均长度 × 0.3
```

**换算成"能钓多少条"**（木竿 2000 耐）：

| 目标鱼 | 单次损耗 | 可钓条数 |
|---|---|---|
| 白品质小鱼 | 2 | ~1000 条 |
| 蓝品质 | 7 | ~285 条 |
| 紫品质 | 12 | ~166 条 |
| 金品质 | 20 | ~100 条 |
| 红品质 | 30 | ~66 条 |

> 这个尺度的用意：**鱼竿几乎不会成为你的瓶颈**（避免频繁修装备打断钓鱼节奏），真正的消耗压力在**鱼线**（20–50 次咬钩就要换）。这符合"鱼线是消耗品、鱼竿是投资品"的常识逻辑。
> **【开放项4】**：要不要加"鱼竿修理"（用材料修复耐久）？我建议加，成本 = 材料 + 鱼币。

## 7. 打窝与鱼饵：品质下限系统 ★（已按你的反馈重构）

> **你的原话**：
> - "决定鱼品质的是打窝料与饵料"
> - "打窝是使得一定区域内上鱼时间缩短以及吸引高级鱼"
> - "饵料用于筛选，比方说大饵料不可能钓到小鱼，也就是说高级饵料是提上鱼品质下限"
>
> 这一节是整个品质系统的**唯一规则来源**。旧版"稀有度惩罚系数"已删除。

### 7.1 两个变量的分工（一句话说清）

| 变量 | 作用 | 玩家心智 |
|---|---|---|
| **窝料（Chum）** | 抬**品质下限**（把低品质鱼排除出鱼池）+ 缩短咬钩时间 | "打窝 = 把好鱼引过来，顺便让它们快点咬" |
| **饵料（Bait）** | 设**品质下限**（大饵钓不到小鱼）+ 定向筛选鱼种 | "换饵 = 换目标，大饵筛掉小鱼" |

**最终品质下限**：

```
品质下限 = max(窝料下限, 饵料下限)
→ 抽鱼时，稀有度低于下限的鱼直接从鱼池中【排除】（不是降低权重，是彻底不出现）
```

### 7.2 窝料（4 种，抬下限 + 缩时间）

> ⚠️ **已按你的反馈重做**：窝料从"60–90 秒的区域窝子"改成"**撒下去会散开、维持 10 分钟的增益**"。

**窝料的两种形态**（对应你说的"会散开，特殊配方可以散到目标层"）：

| 形态 | 表现 | 影响范围 | 谁需要它 |
|---|---|---|---|
| **水面窝**（普通） | 落水后在水面横向散开成一片 | 只影响**表层/中上层/中层**的鱼 | 钓鲫鱼、湖鲈、沙丁鱼、虹鳟 |
| **沉底窝**（特殊配方） | 边下沉边散开，在指定泳层形成一片 | 能影响**底层**的鱼 | 钓黄金鲤、幽渊盲鲟、深潜型大鱼 |

| 窝料 | 形态 | 品质下限 | 咬钩时间 | 持续时间 | 价格 | 说明 |
|---|---|---|---|---|---|---|
| **通用谷物窝** | 水面窝 | 白（不设限） | ×0.75 | **10 分钟** | 80 ¤ | 只缩时间不抬品质，刷钱工具 |
| **腥味肉窝** | 水面窝 | 绿 | ×0.65 | **10 分钟** | 180 ¤ | 从此不再出白鱼 |
| **甜香蜂蜜谷物窝** | 水面窝 | 蓝 | ×0.55 | **10 分钟** | 440 ¤ | 蓝品质起步 |
| **秘制配方窝** | **沉底窝** | 紫 | ×0.45 | **10 分钟** | 1200 ¤ | **唯一能影响底层鱼 + 钓紫以上的前提** |

**增益的三条规则**（已按你的选择定案）：

1. **只在同一片水域生效**——因为窝料是撒在水里的。上岸、跨维度、走到另一个水体，增益立即失效（HUD 会显示剩余时间与失效提示）。
   → 这防止它变成"随身光环"，也让"选钓点"这件事保持意义。
2. **同类窝料不叠加，只取最高品质下限**——撒两个秘制窝不会变成"双倍紫下限"，只是刷新持续时间。
   不同**效果**可以共存：例如"通用谷物窝的时间缩短"和"秘制窝的品质下限"能同时吃（如果实现上允许两种窝料同时生效，见下）。
3. **只有沉底窝能影响底层鱼**——想钓黄金鲤（底层）、幽渊盲鲟（底层）必须用秘制配方窝；用普通水面窝，底层鱼**根本不进鱼池**。

**关于"能不能同时吃两种窝料"**：首版**不允许**——同时只能有一种窝料增益生效，撒新窝会覆盖旧的。理由：避免玩家叠出"时间 ×0.45 + 下限紫"这种过强组合，也避免 UI 显示混乱。
**【开放项29】** 如果你想让玩家能叠（比如一个"时间槽"一个"品质槽"），告诉我，我加双槽窝料系统。

其他规则：
- 窝子半径 3 格，**单水域最多同时 4 个**，超出最早的消失。
- 窝料对**路亚竿效果减半**（掠食鱼不吃窝料）：时间修正折半、品质下限**不生效**。
  → 刻意的平衡：**路亚竿靠饵料和操作钓大货，台钓竿靠窝料刷品质。**
- **视觉优化**（你指定的方向）：窝子的粒子**不做每 tick 逐个生成**，改成"低频批量"——每 8 tick 在窝子区域一次性撒 3–5 个粒子（`bubble` + `fishing` 混合），视觉上依然是持续冒泡，但粒子总数降低约 80%。

### 7.3 饵料（筛选 + 定下限）

**拟饵/饵料的"体型"直接决定能钓到什么体型的鱼**——这就是你说的"大饵料不可能钓到小鱼"：

| 饵料 | 品质下限 | 可钓最大体型 | 体型筛选规则 | 消耗 |
|---|---|---|---|---|
| 面包屑 | 白 | 小型（≤ 1 kg） | 只上小型鱼，**钓不到中大鱼** | 消耗 ×1 |
| 蚯蚓 | 白 | 中型（≤ 4 kg） | 通用 | 消耗 ×1 |
| 玉米粒 | 绿 | 中型（≤ 8 kg） | 草食鱼定向 ×2.2 | 消耗 ×1 |
| 亮片拟饵 | 蓝 | 中型（≤ 15 kg） | **排除所有 ≤ 0.5 kg 的小鱼**；掠食鱼 ×1.8 | 拟饵，耐久 30 |
| 米诺鱼拟饵 | 紫 | 大型（≤ 60 kg） | **排除所有 ≤ 2 kg 的鱼**；掠食鱼 ×2.4 | 拟饵，耐久 25 |
| 浅层刺激拟饵 | 紫 | 大型（≤ 80 kg） | 排除 ≤ 5 kg；中上层掠食鱼 ×2.6 | 拟饵，耐久 20 |
| 活虾 | 紫 | 巨型（无上限） | 排除 ≤ 3 kg；海洋稀有鱼 ×2.5 | 消耗 ×1 |
| 发光饵 | 金 | 巨型（无上限） | 排除 ≤ 5 kg；洞穴/深海 ×3.0，仅黑暗中生效 | 消耗 ×1 |
| 秘制香饵 | 红 | 巨型（无上限） | 排除 ≤ 10 kg；全鱼 ×2.8 + 幸运 +0.25 | 消耗 ×1 |

**筛选规则的三层含义**（写进教程书，玩家必须懂）：

1. **下限排除**：饵料下限以下的鱼**不会咬钩**（不是概率降低）。
2. **上限截断**：面包屑这种小饵**钓不到大鱼**（大鱼对碎屑没兴趣）——所以"用便宜饵碰运气钓红鱼"是不成立的。
3. **定向吸引**：同一档位内，匹配的鱼种权重 ×1.8~3.0（例如发光饵在洞穴里对盲鲟 ×3.0）。

| 赌红品质 | 秘制配方窝 | 秘制香饵 | **紫起步**，排除 <10kg | 唯一能稳定遇到金/红的组合，成本极高 |
| 路亚冲大货 | 窝料无效 | 浅层刺激拟饵 | 紫起步（饵料下限），排除 <5kg | 靠操作赌大货，饵料耐久消耗 |

> **经济平衡的关键**：最高档组合（秘制配方窝 600 + 秘制香饵 750/条）单次成本约 1350 ¤，而一条红鱼平均收益 1500 ¤。**赌红鱼是"高方差投资"**，需要认证宗师才能解锁——这让"宗师"这个认证有真实的经济价值，而不是一个称号。

### 7.5 品质下限的展示方式（玩家必须看得见）

- 改装/钓鱼时，屏幕角落显示当前生效的下限：`品质下限：紫 ▲（窝料） · 体型：≥2kg（米诺）`
- 用不匹配的饵料时给出提示：`当前饵料钓不到 黄金鲤（体型不足）`
- 教程书里有完整的"窝料/饵料对照表"（见 `10-教程书设计.md`）

## 7.6 战斗与 TPS 保障（原版机制冲突应对）

> **你的担忧**：原版对远处实体会降低 tick 频率（DAB：8 格外开始降频，20 格以上降到每 60 tick 一次）。70 格外的浮漂如果被降频，张力判定就会跳帧。
> 完整分析见 `09-原版冲突与渲染优化.md`，这里只记结论：

- 浮漂/拟饵实体在**钓鱼会话期间**必须：① 请求全频率 tick（豁免 DAB/激活范围降频）；② 单独设 `clientTrackingRange`（默认 4 区块 → 提高到 10 区块，可配置）；③ 不参与普通实体剔除。
- 若客户端区块视距 < 抛投距离：客户端保留**"幽灵鱼线"**（用会话同步数据绘制，不依赖实体是否存在），并在 64 格以外用**简化线型**（从竿尖直接连到落点，不做下垂曲率）。
- 会话结束后立即恢复正常剔除，不留常加载负担。

## 8. 边界情况与容错

| 情况 | 处理 |
|---|---|
| 对抗中玩家退出游戏 | 视为逃脱：饵损失，进 4s 冷却，鱼线耐久**不额外扣**（咬钩时已扣） |
| 对抗中玩家死亡 | 立即结束会话，鱼获不进入背包（还没钓上来） |
| 对抗中传送/换维度 | 立即结束会话，饵损失 |
| 服务器 TPS 低（<15） | 所有时序判定按"实际 tick 数"而非墙钟时间，避免低 TPS 下窗口不可完成 |
| 两名玩家在同一格抛竿 | 允许；窝子共享；互不干扰（各自独立会话） |
| 在鱼缸/炼药锅等小水体抛竿 | 水深 < 2 → 浅水池，只出白绿鱼 |
| 玩家背包满时上鱼 | 鱼获直接**掉落在玩家脚下**（不丢失，不阻塞），并提示"背包已满" |
| 鱼竿耐久归零 | 鱼竿断裂音效 + 变成"破损鱼竿"（可修）或直接消失【开放项4】 |
| 鱼线耐久归零 | 鱼线断裂，需在改装界面更换新鱼线 |

## 8.5 实体生命周期与优化（窝料 / 饵 / 浮漂）

> 已按你的决定：**不限数量，只限制同步范围**；**优化从粒子下手**。

| 实体 | 存在时间 | 消失方式 | 同步范围 | 粒子优化 |
|---|---|---|---|---|
| **浮漂/拟饵** | 会话期间 | 会话结束（上鱼/断线/取消）后立即回收 | `clientTrackingRange = 10 区块`（会话期间） | 落水/咬钩时一次性粒子 |
| **抛出的饵料** | **45 秒** | 沉底后计时，到时淡出消失；被鱼咬钩时立即消耗 | **32 格内**（`entitySyncRadiusBlocks`） | 下沉时每 10 tick 1 个气泡 |
| **窝料** | **10 分钟**（增益时长） | 增益结束时窝子淡出 | **32 格内** | **每 8 tick 抛 4 个粒子**（而非每 tick 1 个 → 粒子总数降低约 80%） |

**"不限数量"的兜底保护**（不设硬上限，但防止极端情况拖垮服务器）：
- 同步范围 32 格意味着**远处实体不占带宽**——这是你的选择，也是主要优化手段。
- 若同一区块内实体数超过 **64** 个（极端刷屏，比如有人往水里狂扔饵），服务端会**自动缩短新实体的存活时间**（45s → 10s）而不是拒绝生成。这样既不限制玩家，又不会崩。
- 粒子生成走**批量低频**：一次 tick 内最多生成 8 个粒子，超出部分顺延到下一 tick。

## 10. 本节结论

手感设计的四个"必须做对"（已按你的反馈更新）：

1. **抛投**：蓄力条上的绿区 + 落点误差可视化（地面上显示一个预测落点圈）——让玩家第一次抛竿就能理解"力度"。
2. **咬钩**：浮漂三段预告 + 声音强弱递进——让"提竿"是一个可读、可练、可精通的技巧，而不是运气。**等待时间上限 20 秒，平均 3–6 秒**。
3. **张力**：**鱼线颜色白 → 黄 → 红 → 深红闪烁就是全部反馈**，HUD 只做一条极简细条做辅助——让"放线"成为一个看线就能做的动作，而不是看一堆花哨特效。
4. **品质**：**一句话规则**——"窝料抬下限、饵料定下限，大饵钓不到小鱼"。玩家不需要理解概率表，只需要记住选对窝料和饵料。
