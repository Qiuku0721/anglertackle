## 1. 一句话定位

**《垂纶》/ Angler's Tackle** —— 一个以「**手感优先**」为核心的 Minecraft 钓鱼模组：**抛投物理 + 浮漂/路亚双竿玩法 + 鱼线张力对抗 + 六槽渔具改装 + 鱼类图鉴 + 认证晋升与自定义货币经济**，并保留原版钓鱼作为并存的旧玩法。

> 玩法灵感来自现代战术射击游戏里的钓鱼玩法（机制本身不受版权保护），但**名称、美术、NPC、音效全部原创**，以符合 Modrinth / CurseForge 的上架合规要求。详见 `12-发布与合规策略.md`。

### 4.2 网络现状（三个源被阻断，已用镜像解决）

| 源 | 直连结果 | 解决方案 |
|---|---|---|
| `github.com` | ❌ 连接超时 | JDK 改走**清华镜像**的 Adoptium 目录 |
| `services.gradle.org` | ❌ 连接超时 | Gradle 改走**腾讯镜像** |
| `maven.neoforged.net` | ❌ TCP ECONNRESET | 改走 **`neoforged.forgecdn.net`** 镜像 |
| `api.adoptium.net` · `piston-meta.mojang.com` · `repo1.maven.org` · `plugins.gradle.org` | ✅ 通 | 无需处理 |

**踩过的两个坑（都已解决，写在这里免得重踩）**：

1. **ModDevGradle 把 `neoform-runtime` 等依赖写死在官方源**，`build.gradle` 里的 `repositories {}` 对它无效。
   → 解法：`.gradle-home\init.d\mirror.init.gradle` **全局 URL 重写**，所有含 `maven.neoforged.net` 的仓库自动改写到镜像。
2. **Gradle 以 ISO-8859-1 读取 `gradle.properties`**，而本项目路径含中文（`我的世界mod`），导致 `org.gradle.java.home` 变乱码、构建直接失败。
   → 解法：**不把 JDK 路径写进配置文件**，改由 `tools\gradlew.cmd` 用命令行参数 `-Dorg.gradle.java.home=` 传入。
3. 顺带：`org.gradle.configuration-cache` 必须关闭——MDG 的 `createMinecraftArtifacts` 任务无法序列化。

## 5. 关键术语表（全文统一）

| 术语 | 含义 |
|---|---|
| **台钓竿** | 带浮漂的钓竿，玩法是"等浮漂完全沉入水下 → 提竿" |
| **路亚竿** | 用拟饵引诱掠食性鱼，玩法是"抛投→收线→咬钩→张力对抗→收线到近岸" |
| **张力（Tension）** | 路亚玩法核心数值，**用鱼线颜色表达**：白（安全）→ 黄（注意）→ 红（危险）→ 深红闪烁（即将断线） |
| **泳层** | 拟饵在水中的深度：表层 / 中层 / 底层，不同鱼在不同泳层 |
| **窝料** | 撒入水中形成"窝子"，**缩短上鱼时间 + 抬高品质下限** |
| **饵料** | **筛选器**：设定品质下限 + 体型门槛（大饵钓不到小鱼） |
| **品质下限** | 低于此稀有度的鱼**直接不进入鱼池**；`品质下限 = max(窝料下限, 饵料下限)` |
| **咬钩（Hook）** | 鱼真正吃饵的瞬间，**咬钩即扣耐久**（你的规则） |
| **切线** | 张力满导致鱼线崩断，鱼逃脱，损失鱼饵并进入冷却 |
| **幽灵鱼线** | 当浮漂超出客户端视距/追踪范围时，客户端仍用会话数据绘制鱼线（保证张力反馈不断） |
| **渔具包** | 参考官方设定：装渔具的随身包，不占主背包、死亡不掉落 |
| **认证等级** | 进阶 / 资深 / 大师 / 宗师，达到条件后找 NPC 考核晋升 |
| **鱼币（Fish Coin）** | 本模组自定义货币，卖鱼与任务获得，买渔具与鱼饵 |
