## 1. 素材来源清单（附许可证说明）

| 来源 | 内容 | 许可证 | 可用性 |
|---|---|---|---|
| [Kenney.nl](https://kenney.nl/assets) | 大量 2D/3D 素材包（含"Fish Pack"、UI Pack、界面元素） | **CC0**（公共领域，无需署名） | ✅ 首选，最省心 |
| [OpenGameArt.org](https://opengameart.org/) | 社区 2D 素材，鱼类/UI/图标丰富 | 每个素材不同：CC0 / CC-BY 3.0 / CC-BY-SA / GPL | ⚠️ 只能用 CC0 或 CC-BY；**CC-BY-SA 和 GPL 不能用**（会传染整个模组） |
| [itch.io 免费素材](https://itch.io/game-assets/free) | 像素鱼、钓鱼小游戏 UI | 各作者不同 | ⚠️ 逐个核对，只用明确 CC0 的 |
| [Game-icons.net](https://game-icons.net/) | 3000+ 单色图标（鱼、鱼钩、鱼竿、奖杯等） | **CC-BY 3.0** | ✅ 适合做 GUI 图标（需在模组内附署名文件） |
| [Freesound.org](https://freesound.org/) | 音效（水花、卷线、鱼尾拍水） | 多为 CC0 / CC-BY | ✅ 只用 CC0 或 CC-BY |
| [Pixabay](https://pixabay.com/) / [Unsplash](https://unsplash.com/) | 照片（仅作**参考**，不直接用） | Pixabay 自有许可 | ⚠️ 照片不能直接做像素贴图，只用来对照鱼的形态与配色 |

**许可证底线（必须遵守）**：
1. 只用 **CC0** 或 **CC-BY**。**绝不用 CC-BY-SA / GPL / 非商业限制（NC）** 的素材——它们会污染整个模组的授权。
2. CC-BY 素材必须在 `assets/anglertackle/CREDITS.txt` 里列出：素材名 + 作者 + 来源 URL + 许可证。
3. 我在 `docs/07-美术与素材.md` 附录里维护一份**实际使用的素材清单**，每次引入新素材就追加一行。
4. 所有成品贴图都经过重绘/量化改造，属于"衍生作品"，但仍需保留原始署名。

## 2. 像素化改造流程（保证 MC 风格统一）

```
原始素材（各种尺寸/风格/色彩数）
        │
        ├─ ① 选型：挑形态接近的（鲈形/鲨形/鲤形/鲟形）
        │
        ├─ ② 抠图 + 缩放到目标尺寸（最近邻插值，不用双线性！否则糊）
        │      工具：Python + Pillow（你机器上有 Python）
        │
        ├─ ③ 色彩量化到 MC 风格调色板
        │      每张贴图限制 8–14 色（原版物品贴图通常 6–12 色）
        │      用固定调色板（见 §3）而不是自由取色
        │
        ├─ ④ 加 1px 深色描边（原版物品的辨识度来自描边）
        │
        ├─ ⑤ 加高光/阴影：左上光源，右上高光 1–2 像素，右下暗部
        │
        ├─ ⑥ 抖动（dithering）处理渐变，避免色带
        │
        └─ ⑦ 人工微调：眼睛、鳍、鳞片纹理（这一步必须手调，机器做不好）
```

### 2.1 我会写的处理脚本

`tools/pixelize.py`（M7 阶段交付）：

```python
# 功能：
#  1. 批量读取 tools/raw/ 下的原始素材
#  2. 自动抠掉纯色背景（可选）
#  3. 缩放到指定尺寸（最近邻）
#  4. 量化到 MC 调色板（中位切分 + 固定色板映射）
#  5. 加描边 + 高光
#  6. 输出到 src/main/resources/assets/anglertackle/textures/
# 内置"对照预览"：把结果放大 4 倍拼成一张对比图，方便你一眼看效果
```

依赖：`pip install pillow`（我会在工作区建虚拟环境，不污染系统 Python）。

## 5. 工作量与优先级

| 阶段 | 美术内容 | 处理方式 |
|---|---|---|
| M1 | 木竿（占位）+ 1 条鱼 + HUD 三件套 | **程序生成占位色块**（写个脚本生成纯色带描边的贴图），不阻塞开发 |
| M2 | 5 档竿 ×2 类型 + 线/钩/饵 + 改装 GUI | 占位 + 手工像素化 |
| M3 | 10 条鱼 + 图鉴 GUI | **主要美术工作**，需要处理素材 |
| M4 | NPC + 浮漂 + 结构 | NPC 皮肤手绘（64×64） |
| M5 | 商店/任务 GUI + 鱼币 | 基于 Kenney UI Pack 改造 |
| M6 | 水族箱 + 鱼架 + 排行榜 | 方块贴图手绘 |
| M7 | **全部音效 + 粒子 + 动画 + 精修** | 集中处理 |
| M8 | 扩展鱼种（20–30 种） | 脚本批量 + 人工微调 |
