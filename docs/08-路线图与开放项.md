# 08 · 开发路线图、验收标准与开放项

> 📌 **开工必读** —— 本文件是《垂纶》策划族的一员。动手前先读 `docs/CONVENTIONS.md`（协作规则 + 每轮自我暗示）与 `docs/接力.md`（接手须知）；项目记忆只认 `docs/` 下的文件。

> ## ⚠ 本文档中「蓄力绿区 / 力度决定落点」的描述**已废弃**
>
> 实际实现：**抛投距离由玩家视角俯仰决定**，与蓄力条无关。
>
> | 视角 | 距离 |
> |---|---|
> | 低头看水面 | 约 **8 米** |
> | 平视 | 约 **16 米** |
> | 抬头（≤45°） | 约 **24 米** |
>
> 蓄力条只影响 HUD 上那条进度条的显示节奏（`Config.chargeTimeSeconds`），
> **不参与落点计算**。原「绿区宽度 / 落点误差」相关配置项已从 `Config.java` 删除。
>
> 依据：`fishing/FishingManager.java` 的 `castByLook()`。
> （2026-09-30 核实代码后补注：这条错误曾误导过一次教程审计。）
>

## 1. 八个里程碑

> 原则：**每个里程碑结束都给你一个能跑起来的构建**，你实测手感后再进下一个。手感不过关绝不往下堆内容。

### M1 · 手感原型（最重要）

| 项 | 内容 |
|---|---|
| 交付 | 可运行的模组：木钓竿（台钓 + 路亚各一）+ 1 种鱼（河流鲫鱼）+ 完整状态机 + 占位 HUD |
| 包含 | 蓄力抛投 · 抛物线飞行实体 · 落水判定 · 台钓三段浮漂动画 · 提竿窗口 · 路亚泳层与收线 · 张力模型（**鱼线颜色反馈**）· 鱼体力与挣扎 · 上鱼结算 · 耐久扣除（你的规则） |
| **新增必做** | **① 幽灵鱼线 + 落点标记**（渲染距离兜底，见 `09` §4.3）**② 浮漂追踪范围与强制 tick 的实测验证**（`/anglertackle debug tickrate`） |
| 美术 | 全部程序生成占位色块，音效用原版音效顶替 |
| 验收 | 你能完整完成"抛竿 → 咬钩 → 提竿 → 张力对抗 → 上鱼"全流程，并且能明确说出"哪里手感不对"；**把渲染距离调到 4 区块、抛 70 格，仍能看到鱼线与落点标记** |
| 依赖 | JDK 21 环境就绪、Gradle 首次构建成功 |
| 预计规模 | ~22 文件 / ~3000 行 |

**M1 的验收方式**：我会准备一张"手感反馈表"，列出 20 个可调参数（蓄力时长、绿区宽度、窗口时长、张力增长速率、冲刺频率……）。你玩完直接勾"太快/太慢/刚好"，我按表调。**可能要来回 2–4 轮**，这部分时间花得最值。

## 2. 总验收标准（项目"完成"的定义）

| 维度 | 标准 |
|---|---|
| 手感 | 抛投/咬钩/张力/收线四环节的输入→反馈延迟 ≤ 1 tick；**张力以鱼线颜色为主反馈**，无 HUD 也能玩 |
| 节奏 | 台钓平均等待 3–6s（上限 20s）；路亚无等待；打窝后等待再降 35–55% |
| 内容 | ≥ 10 种鱼（M3）/ ≥ 30 种（M8）；6 档稀有度全覆盖；4 类水体各有专属鱼 |
| 品质 | 窝料/饵料的下限规则**严格生效**：低于下限的鱼一条都不能出现；小饵钓不到大鱼 |
| 装备 | 5 档竿 × 2 类型，四部件可自由改装，属性差异明显可感 |
| 经济 | 完整闭环，中期玩家每小时 600–1500 鱼币，装备消耗节奏合理 |
| 耐久 | 严格符合你的规则：咬钩即扣（与成败无关）、鱼线每次 −1、越高级鱼对鱼竿损耗越大 |
| 多人 | 服务端权威、状态同步、排行榜可信（即便暂不实测，代码层面保证） |
| **原版兼容** | **零冲突**：不改原版 `FishingHook`/原版钓竿行为；左键拦截仅在会话中生效；可与其他钓鱼模组共存；可服务端单装 |
| **渲染鲁棒性** | 70 格抛投在 4 区块视距下仍能看到**落点标记与鱼线（幽灵线）**；张力颜色反馈不因实体消失而中断 |
| **可教学性** | 教程书能让"完全没看文档的玩家"在 3 分钟内钓上第一条鱼；FAQ 覆盖新手 90% 的困惑 |
| 配置 | 每个子系统可独立关闭；关键数值可通过 `balance.json` 调整 |
| 授权 | 只使用 CC0/CC-BY 素材，附带 `CREDITS.txt` 署名 |
