> 📌 **开工必读** —— 本文件是《垂纶》策划族的一员。动手前先读 `docs/CONVENTIONS.md`（协作规则 + 每轮自我暗示）与 `docs/接力.md`（接手须知）；项目记忆只认 `docs/` 下的文件。

> ## ⚠ 本文档中「蓄力绿区 / 力度决定落点」的描述**已废弃**
>
> 实际实现：**抛投距离由玩家视角俯仰决定**，与蓄力条无关。
>
> | 视角 | 距离 |
> |---|---|
> | 低头看水面 | 约 **8 米** |
> | 平视 | 约 **16 米** |
> | 抬头（≤45°） | 约 **24 米** |
>
> 蓄力条只影响 HUD 上那条进度条的显示节奏（`Config.chargeTimeSeconds`），
> **不参与落点计算**。原「绿区宽度 / 落点误差」相关配置项已从 `Config.java` 删除。
>
> 依据：`fishing/FishingManager.java` 的 `castByLook()`。
> （2026-09-30 核实代码后补注：这条错误曾误导过一次教程审计。）
>

> 你的要求："**mod 内容需要整理为教程书通俗易懂地讲述给玩家**"。

## 3. 逐章内容（可直接使用的成稿文案）

### 第一章 · 三分钟学会钓鱼

> **本页目标**：让完全的新手在 3 分钟内钓上第一条鱼。

```
【第一步】做一根钓竿
   木棍 ×3 + 线 ×1  →  木钓竿（台钓竿）
   不知道选哪种？先用台钓竿，它更简单。

【第二步】找一个有水的地方
   水深至少 2 格。河、湖、海边都行。
   ⚠ 水太浅只能钓到小鱼。

【第三步】长按右键蓄力
   屏幕下方会出现一条蓄力条。
   松手抛竿。
   💡 蓄力条上的【绿色区域】是最佳力度，落在绿区抛得最准。

【第四步】等浮漂动
   浮漂会先轻轻抖两下（鱼在试探，别动！）
   然后【整个沉进水里】——
   👉 这时候立刻按右键提竿！

【第五步】收线
   鱼上钩后会挣扎，你需要和它拔河：
   · 按住右键 = 收线（鱼会靠近，但线会绷紧）
   · 按住左键 = 放线（线会松下来，但鱼会跑远）
   · 看线的颜色！白色安全，变黄要小心，变红赶紧放线！

【第六步】把鱼拉上岸
   鱼累了（体力条空了）而且离你够近，就钓上来了。
```

> **本页一句话**：**浮漂沉下去就提竿，线变红就放线。**

---

### 第二章 · 为什么鱼不上钩？

> **本页目标**：把新手 90% 的困惑直接消掉。

| 你的问题 | 原因 | 怎么解决 |
|---|---|---|
| 浮漂一直不动 | 鱼还没来 | 等 3–8 秒很正常；**打窝能明显加快**（见第四章） |
| 提竿了但什么都没钓到 | 提竿太早或太晚 | 要等浮漂**完全沉进水里**再提，不是抖一下的时候 |
| 鱼跑了 | 张力太大断线了 | 线变红就立刻松开右键，改按左键放线 |
| 一直钓到小鱼 | 饵料太小、没打窝 | 换大一点的饵料 + 打窝（见第四章） |
| 高级鱼从来不来 | 窝料/饵料档次不够 | 用秘制配方窝 + 米诺鱼拟饵以上 |
| 提示"钓不到 XX 鱼" | 饵料体型太小 | 大饵才能钓大鱼，换饵 |
| 我的线很快就断了 | 鱼线耐久只有 20–50 次 | 这是正常的，鱼线是消耗品，去渔具铺买新的 |
| 抛不到远处的深水 | 鱼线长度不够 | 换更高级的鱼线（麻线 30 格 → PE 线 70 格） |

> **本页一句话**：**钓不到鱼，八成是饵不对或者窝没打。**

### 第三章 · 装备：从木竿到合金竿

```
【鱼竿】分两种玩法
  ┌─ 台钓竿：看浮漂下沉提竿。简单、能打窝、适合刷数量。
  └─ 路亚竿：用假饵引诱大鱼，靠手感拔河。难、但能钓到大货和稀有鱼。

【五种材质】↗ 越往下越强，但也更贵
  木竿    耐久 2000   能钓 8kg 以下
  铁竿    耐久 3500   能钓 20kg 以下
  金竿    耐久 2500   窗口时间最长（最好提竿），但耐久低
  钻石竿  耐久 5000   能钓 40kg 以下
  合金竿  耐久 8000   什么都能钓

  ⚠ "能钓多少 kg"是硬限制！木竿永远钓不到鲨鱼，不是运气问题。

【四个部件】可以在渔具工作台自由改装
  ① 竿身 —— 决定耐久、承重、窗口时间
  ② 鱼线 —— 决定线长、耐久（20~50 次咬钩）、抗断线能力
  ③ 鱼钩 —— 小加成（窗口时间、大个体概率、夜钓效率）
  ④ 拟饵 —— 路亚专用，决定能钓什么体型

  💡 鱼竿是投资品（能用很久），鱼线是消耗品（每次咬钩 -1）。

【附魔】
  海之眷顾 → 更容易出稀有鱼和大个体
  饵钓     → 鱼咬钩更快
  耐久/经验修补 → 保护你的鱼竿
```

> **本页一句话**：**先升级鱼线（线长决定你能钓多远），再升级鱼竿（承重决定你能钓多大）。**

### 第四章 · 窝料与饵料：钓好鱼的秘诀 ★核心

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   记住这一句话，你就懂了一半：
   【窝料决定鱼有多好，饵料决定鱼有多大】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【窝料 = 把好鱼引过来】
   撒在水面上，形成一个"窝子"（能看到气泡）。
   作用有两个：① 鱼咬钩更快  ② 把低品质的鱼筛掉

   通用谷物窝  →  不筛品质，只加快咬钩   （便宜，刷小鱼用）
   腥味肉窝    →  绿品质起步            （不再出白鱼）
   甜香蜂蜜谷物窝    →  蓝品质起步
   秘制配方窝  →  紫品质起步            （想钓金鱼红鱼必须用）

【饵料 = 只让目标鱼咬钩】
   小饵钓不到大鱼，大饵钓不到小鱼。

   面包屑      只能钓 1kg 以下的小鱼
   蚯蚓        4kg 以下
   玉米粒      8kg 以下
   亮片拟饵    排除 0.5kg 以下的小鱼（路亚）
   米诺鱼拟饵  排除 2kg 以下的鱼（路亚）
   浅层刺激拟饵    排除 5kg 以下的鱼（路亚，钓浅层）
   活虾        什么都能钓（贵）
   发光饵      什么都能钓，洞穴和深海特别好用
   秘制香饵    排除 10kg 以下，全部鱼更容易咬（最贵）

【组合推荐】
   想快速赚钱       通用谷物窝 + 面包屑
   想钓蓝品质       甜香蜂蜜谷物窝 + 亮片拟饵
   想赌金色大鱼     秘制配方窝 + 米诺鱼拟饵
   想钓红色传说     秘制配方窝 + 秘制香饵（很烧钱，但一条就回本）
```

> **本页一句话**：**窝料抬下限，饵料定下限；两个搭配，才能钓到你想要的那条鱼。**

### 第五章 · 鱼的生活习性

```
【在什么地方】不同水域有不同的鱼
   河流    鲫鱼、湖鲈、虹鳟、黄金鲤
   海洋    沙丁鱼（近岸）、灰鲭鲨（深海）、蓝鳍金枪鱼（远海雷暴）
   沼泽    蓝鳃太阳鱼、斑点雀鳝
   洞穴    幽渊盲鲟（唯一金品质，要用发光饵）
   ⚠ 深海 = 离岸 60 格以上 + 水深 8 格以上

【什么时间】
   清晨  → 掠食鱼活跃（虹鳟最爱）
   黄昏  → 一天中最好的时段
   夜晚  → 夜行鱼出没（雀鳝、盲鲟）
   白天  → 普通鱼为主

【什么天气】
   下雨  → 鱼咬钩快 30%，虹鳟特别活跃
   雷暴  → 咬钩最快，而且【蓝鳍金枪鱼只在雷暴出现】

【水多深】
   2 格以下 → 只有小鱼
   4 格以上 → 中型鱼
   8 格以上 → 深海大鱼
```

> **本页一句话**：**想钓什么鱼，先看它在哪、什么时候出来、要多深的水。**

### 第七章 · 认证与晋级

```
【钓鱼等级】靠钓到的鱼升级，一共 20 级。

【认证】找老柯考核，一共 5 档：

  新手  →  一开始就是         可钓：白绿鱼
  进阶  →  等级 5 + 钓到 3 种蓝鱼    解锁：沼泽、蓝鳃太阳鱼、拟饵
  资深  →  等级 10 + 钓到紫鱼 + 图鉴 40%   解锁：黄金鲤、碳氟线
  大师  →  等级 15 + 钓到金鱼 + 图鉴 70%   解锁：洞穴盲鲟、鲨鱼、发光饵
  宗师  →  等级 20 + 钓到红鱼 + 图鉴 90%   解锁：蓝鳍金枪鱼、PE 线、秘制香饵

  💡 认证不是摆设：不升到大师，你连鲨鱼都碰不到。
```

> **本页一句话**：**认证是解锁更高级鱼和装备的唯一钥匙，别忘了定期去找老柯考核。**

### 第八章 · 鱼币与渔具铺

```
【鱼币 ¤】是本模组的货币，卖鱼获得。

  白鱼 3 ¤      蓝鱼 30 ¤      金鱼 330 ¤
  绿鱼 10 ¤     紫鱼 99 ¤      红鱼 1500 ¤

  同一条鱼，越重越值钱（最高 2.5 倍）；
  尺寸评级越好越值钱（纪录级 2.5 倍）。

【怎么赚钱快】
  新手期  谷物窝 + 面包屑，快速刷小白鱼（约 200–400 ¤/小时）
  中期    甜香蜂蜜谷物窝 + 亮片拟饵，刷蓝紫鱼（约 600–1500 ¤/小时）
  后期    秘制窝 + 好饵，赌金红大鱼（约 1000–4000 ¤/小时，但烧钱）

【钱花在哪】
  鱼饵、鱼线（消耗品）、窝料、鱼钩、拟饵、鱼缸、渔具包升级
```

> **本页一句话**：**小鱼稳定但慢，大鱼烧钱但一条回本——自己选路子。**

### 第九章 · 水族箱与展示

```
【水族箱】用玻璃 + 水 + 鱼币买，放下后右键打开。
   把钓到的鱼放进去，它们会在里面游来游去。
   鱼会慢慢长大（5 分钟长 1%），长到更大就能取出卖更多钱。
   记得喂食！不喂食鱼会变瘦。

【鱼架】把鱼挂在墙上展示，给基地加点气氛。

【观赏值】水族箱里鱼的稀有度和大小会累积"观赏值"，
         放在基地里能给附近玩家一点幸运加成。
```

> **本页一句话**：**钓到的稀有鱼别急着卖，放进水族箱展示，还能长大卖更多。**

### 第十章 · 十大高手技巧

```
 1. 抛竿落点越远，越容易碰到大鱼和稀有鱼。
 2. 在船上抛竿，射程 +10%。
 3. 黄昏和雷暴是最高效的两个时段，别错过。
 4. 线变红时不要硬拉——松一下线，张力以 2 倍速度回落。
 5. 鱼的挣扎有预告（水面箭头），提前按对方向能省很多体力。
 6. 抽动拟饵（连续点按）能触发掠食反应，咬钩率翻倍。
 7. 打窝后别急着抛——等 2 秒让鱼聚过来。
 8. 想刷纪录级个体：用宽门钩（大个体权重 +30%）+ 海之眷顾附魔。
 9. 鱼线耐久只剩 3 点时别钓大的，先去换线——断线会额外扣 5 点。
10. 图鉴记录是永久的：卖掉、送人、吃掉都不影响记录，放心卖。
```

> **本页一句话**：**技巧的核心只有两个——看懂线，看准时机。**

## 5. 文案口吻规范（写给未来的自己）

| 规则 | 反例 | 正例 |
|---|---|---|
| **不说数值公式** | "张力 T ∈ [0,100]，82 以上进入红区" | "线变红就赶紧放线" |
| **先说做什么，再说为什么** | "因为张力模型会累积超时计时器……" | "松手放线，线就不会断" |
| **用鱼的角度解释** | "饵料体型筛选参数" | "大鱼对碎屑没兴趣，所以小饵钓不到它" |
| **一句话总结每章** | — | 每章末尾都有"本页一句话" |
| **允许玩家跳过** | 强制读完才能钓鱼 | 教程书是**查阅工具**，不是必读门槛 |
| **不剧透全部** | 直接把红鱼坐标写出来 | 保留"发现"的惊喜，只给线索 |

## 6. 与图鉴界面的关系

| | 教程书 | 图鉴 GUI |
|---|---|---|
| 定位 | "怎么玩" | "我钓到了什么" |
| 内容 | 机制、规则、技巧 | 个人记录、完成度、尺寸评级 |
| 数据来源 | 静态文案 + 动态鱼表 | 玩家存档（Attachment） |
| 更新频率 | 版本更新时 | 每次上鱼实时更新 |

两者**共享**：鱼种数据（JSON）、贴图、稀有度配色 → 一处改，两处生效。
