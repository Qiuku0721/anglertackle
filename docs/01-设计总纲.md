# 01 · 设计总纲

> 📌 **开工必读** —— 本文件是《垂纶》策划族的一员。动手前先读 `docs/CONVENTIONS.md`（协作规则 + 每轮自我暗示）与 `docs/接力.md`（接手须知）；项目记忆只认 `docs/` 下的文件。

## 1. 设计目标

做一个"**愿意专门为了钓鱼上线**"的 Minecraft 模组，而不是"多了几个鱼的钓鱼模组"。

判定成功的三条标准：

1. **手感可辨**：闭着眼也能靠音效和张力条判断"现在该收线还是该放线"，抛投的力度手感有真实反馈。
2. **有稀有度快感**：钓到红色品质鱼时有明确的仪式感（画面、音效、全服播报、图鉴点亮）。
3. **有长期目标**：认证考核 → 解锁更高级渔具/鱼种 → 挑战更大尺寸/重量的同种鱼，形成无限延伸的追求。

## 2. 设计原则（优先级从高到低）

| 优先级 | 原则 | 具体含义 |
|---|---|---|
| P0 | **手感优先** | 抛投/咬钩/张力/收线四个环节的输入延迟与反馈必须调到位；宁可少做 30 种鱼，也要把这四个环节做扎实 |
| P1 | **服务端权威** | 所有判定（咬钩、张力、逃脱、重量随机、耐久扣除、鱼币）都在服务端算；客户端只发"意图"和渲染。防作弊，且为未来的多人/服务器场景留路 |
| P2 | **数据驱动** | 鱼种、鱼饵、窝料、商店价格、认证考核全部走 JSON 数据包，加鱼不用改代码、不用重新编译。这直接决定后续"从 10 种扩到 80 种"的成本 |
| P3 | **数值可外置** | 所有可调参数集中在 JSON + 一个 `balance.json`，方便你自己改数值做平衡 |
| P4 | **不破坏原版** | 不替换原版钓鱼竿、不改原版战利品表行为；新系统通过新物品/新方块接入 |
| P5 | **MC 风格一致** | 像素风、16×16 基准、配色接近原版；不引入写实贴图 |
| P6 | **可关闭** | 每个子系统（图鉴/排行榜/水族箱/比赛）都能在配置里单独关掉，方便塞进整合包 |

## 4. 与《三角洲行动》的对应关系（哪些照搬、哪些改造）

| 三角洲机制 | 本模组做法 | 理由 |
|---|---|---|
| 渔具包装钓鱼装备 | **照搬**，叫「渔具包」 | 保住"钓鱼不占背包"的爽感，同时你又要鱼获占格——两件事不冲突：渔具包只装竿/线/饵，鱼获进主背包 |
| 台钓竿看浮漂下沉提竿 | **照搬 + 强化**：加"微动→试探→下沉"三段预告动画 | 直接"随机下沉"没有技巧感，三段预告让玩家有读秒判断 |
| 路亚竿张力白/黄/红 | **照搬为数值三段**，红区停留计时断线 | 官方手感的核心，必须做 |
| 鱼挣扎方向、向反方向拉杆 | **改造**：MC 里做不了 3D 拉杆，改成"鱼的挣扎方向 = 左右变向"，玩家用 A/D（或左右方向键）抵消 | 保留"要往反方向使劲"的博弈感 |
| 钓鱼等级 + 找 NPC 考核晋升认证 | **照搬**，进阶/资深/大师/宗师四阶 | 长线目标，成本低收益高 |
| 图鉴记录最高稀有度、长度/重量最值 | **照搬**，并加"尺寸评级（幼/普通/优质/极品/纪录）" | 加一层随机性追求，让同种鱼值得反复钓 |
| 钓鱼专属扩充包（不占原扩充槽位） | **照搬**为独立页签 | 鱼获分类清晰 |
| 官方"乔·里德"NPC | **照搬**：自定义 NPC「老渔夫 老柯」+ 任务 + 商店 + 考核 | 你已选自定义 NPC |
| 全服钓鱼排行榜 | **照搬**，按"单鱼最大重量/长度"和"图鉴完成度"两个榜 | 单人也能看自己的历史最佳 |
| 局内钓鱼评价（钓稀有鱼解锁） | **照搬 + 扩**：10 种称号评价 | 便宜的成就感 |
| 哈夫币 | **改造**为「鱼币」，独立货币 | 你已选自定义货币 |
| 撤离（带出才算收益） | **不做**（Minecraft 无撤离概念）；风险感改由"切线损失鱼饵 + 耐久损耗"承担 | 强行做撤离会破坏 MC 体验 |

## 5. 三条设计红线（写给未来的自己）

1. **不做"纯等待"玩法**。玩家抛竿后如果只能干等 20 秒，那就是失败设计。台钓的等待要短（3–15 秒），并且要用浮漂微动、水面涟漪、音效持续给反馈；路亚则完全不等待（靠收线主动找鱼）。
2. **不做数值碾压**。高级渔具 = 更多选择（能钓更深/更大的鱼、抗断线），不是"低级竿钓不到鱼"。低级竿在浅水依然能稳定钓到白绿品质鱼。
3. **不做不可逆惩罚**。切线只损失鱼饵 + 耐久 + 一小段冷却，不损失已钓到的鱼、不掉落背包。休闲玩家不能被劝退。

## 6. 与"手感优先"对应的开发顺序

```
里程碑 M1（手感原型，无美术无内容）
  木竿 + 1 种鱼 + 完整抛投/浮漂/张力/上鱼流程 + 占位贴图
  → 你实测手感，反复调整参数
  ↓
里程碑 M2（装备系统）
  五档竿 + 鱼线 + 鱼钩 + 鱼饵 + 分层改装界面 + 耐久系统
  ↓
里程碑 M3（鱼类与图鉴）
  10 种鱼 + 稀有度 + 尺寸重量 + 图鉴 GUI
  ↓
里程碑 M4（世界与钓点）
  鱼池分配 + 水深 + 时间天气 + 打窝
  ↓
里程碑 M5（经济与 NPC）
  鱼币 + 鱼商商店 + 老柯 NPC + 任务 + 等级考核
  ↓
里程碑 M6（展示与社交）
  鱼架/展览 + 水族箱方块 + 排行榜 + 全服播报
  ↓
里程碑 M7（美术替换）
  CC0 素材像素化 + 音效 + 粒子 + 动画
  ↓
里程碑 M8（打磨与扩展）
  平衡、配置文件、整合包兼容、鱼种扩到 30–40
```
