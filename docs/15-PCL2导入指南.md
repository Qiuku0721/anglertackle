# 15 · PCL2 启动器导入指南

> 📌 **开工必读** —— 本文件是《垂纶》策划族的一员。动手前先读 `docs/CONVENTIONS.md`（协作规则 + 每轮自我暗示）与 `docs/接力.md`（接手须知）；项目记忆只认 `docs/` 下的文件。

> 目标：**一次导入就进游戏，不报错**。
> 自检脚本：`node tools/verify-jar.js`（交付前跑一遍，通过才分发）

---

## 0. 三条硬性前提（不满足必报错）

| # | 前提 | 说明 | 怎么确认 |
|---|---|---|---|
| 1 | **Minecraft 必须是 1.21.1** | 模组的 `minecraft` 版本范围写死为 `[1.21.1,1.21.2)`，1.20.x / 1.21.4 都会被拒绝加载 | PCL2 主界面左上角显示 "1.21.1" |
| 2 | **加载器必须是 NeoForge 21.1.x** | 这是 **NeoForge** 模组，**不是 Forge、不是 Fabric** | PCL2 版本列表里该版本名字后面带 "NeoForge" |
| 3 | **Java 必须 ≥ 21** | NeoForge 21.1.x 要求 Java 21；Java 17 会报 `UnsupportedClassVersionError`。**Java 22 也可以**（只是本项目开发用的 21） | PCL2 → 设置 → 启动选项 → Java 路径 |

> ⚠️ 你系统里装的是 **Java 22**，能跑，但**推荐用 Java 21**（NeoForge 官方测试版本）。
> 本项目工作区里已经有一个现成的 Temurin 21：`.jdk\jdk-21.0.12.1+1\bin\javaw.exe`
> 直接在 PCL2 的 Java 路径里选这个文件就行（不用另外装）。

## 1. 导入步骤（PCL2）

### 第一步 · 新建一个专用版本（别污染你现有的整合包）

```
PCL2 → 版本设置 → 版本列表 → 右上角「安装新游戏版本」
  ├─ 游戏版本：1.21.1
  ├─ 加载器：NeoForge（在列表里勾选，右侧选 21.1.252 或最新的 21.1.x）
  └─ 点击「开始安装」
```

> PCL2 会自动下载 NeoForge 并装好。这一步需要联网，国内网络如果慢，
> 可以在 PCL2 设置里把下载源切成"镜像源"。

### 第二步 · 找到 mods 文件夹

```
PCL2 → 版本设置（选中刚装好的 1.21.1-NeoForge）→ 左下角「打开版本文件夹」
   └─ 进入 mods 文件夹（没有就自己新建一个，名字必须是小写 mods）
```

### 第三步 · 放入 jar

把 **`build\libs\anglertackle-1.0.1.jar`** 复制进 `mods` 文件夹。

**注意**：
- 放的是 **`anglertackle-1.0.1.jar`**
- **不要**放 `anglertackle-1.0.1-sources.jar`（那是源码包，放进 mods 会报错）
- 不要解压 jar，直接放压缩包本身

### 第四步 · 检查 Java

```
PCL2 → 设置 → 启动选项 → Java 路径
  └─ 选 Java 21（推荐）：
     C:\Users\LENOVO-\Documents\dsh\我的世界mod\.jdk\jdk-21.0.12.1+1\bin\javaw.exe
```

### 第五步 · 启动并验证

1. 启动游戏 → 主菜单
2. 检查：**模组列表里有「垂纶 Angler's Tackle」**（PCL2 的"模组管理"按钮里也能看到）
3. 开创造模式，物品栏找「**垂纶**」页签 → 应该看到 10 个物品，且**贴图正常**（不是紫黑格）

## 2. 常见报错与排查（按出现频率排序）

| 现象 | 原因 | 解决 |
|---|---|---|
| 启动器提示"这个模组需要 NeoForge" | 装成了 Forge 或 Fabric | 重装版本，加载器选 **NeoForge** |
| `Mod anglertackle requires minecraft [1.21.1,1.21.2), got 1.20.1` | 游戏版本不对 | 版本必须是 **1.21.1** |
| `UnsupportedClassVersionError: class file version 65.0` | Java 版本太低（< 21） | PCL2 里把 Java 换成 21 |
| 启动到一半崩溃，日志末尾有 `anglertackle` | 模组加载错误 | 把 `.minecraft/logs/latest.log` 发我 |
| 物品是**紫黑格**，或名字显示 `item.anglertackle.xxx` | 资源包/语言文件没加载 | 确认放的是正式 jar（不是 sources）；把日志发我 |
| 物品栏里**没有「垂纶」页签** | 模组没被加载 | 检查 mods 文件夹里是不是 `-sources.jar` 或解压后的文件夹 |
| 游戏能进但抛竿没反应 | 手上拿的不是本模组钓竿，或没对着水面 | 拿「木台钓竿」，对着**至少 2 格深的水面**长按右键 |

## 4. 已知的"不算错误但你会看到"的现象

| 现象 | 说明 | 是否要处理 |
|---|---|---|
| 模组列表里显示 "Angler's Tackle" 而不是中文名 | `displayName` 是英文（上架需要） | 不需要，正常 |
| 游戏日志里有 `experimental` 或 `deprecated` 提示 | 来自 NeoForge 自身或其他模组 | 不需要 |
| 抛竿后看不到浮漂，只有一条线和方框 | **你渲染距离 < 抛投距离**，此时走的是"幽灵鱼线"兜底（设计如此） | 拉近一点或调高渲染距离 |
| F3 调试屏没有额外信息 | 调试命令是 M1 之后再加的 | — |
| 手上拿钓竿时左键不能挖方块 | **只在"提竿窗口 / 对抗中"才拦截左键**，其他时候正常 | 不需要；若确实异常告诉我 |
