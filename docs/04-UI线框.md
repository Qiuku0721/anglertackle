# 04 · UI 线框与交互流程

> 📌 **开工必读** —— 本文件是《垂纶》策划族的一员。动手前先读 `docs/CONVENTIONS.md`（协作规则 + 每轮自我暗示）与 `docs/接力.md`（接手须知）；项目记忆只认 `docs/` 下的文件。

> ## ⚠ 本文档中「蓄力绿区 / 力度决定落点」的描述**已废弃**
>
> 实际实现：**抛投距离由玩家视角俯仰决定**，与蓄力条无关。
>
> | 视角 | 距离 |
> |---|---|
> | 低头看水面 | 约 **8 米** |
> | 平视 | 约 **16 米** |
> | 抬头（≤45°） | 约 **24 米** |
>
> 蓄力条只影响 HUD 上那条进度条的显示节奏（`Config.chargeTimeSeconds`），
> **不参与落点计算**。原「绿区宽度 / 落点误差」相关配置项已从 `Config.java` 删除。
>
> 依据：`fishing/FishingManager.java` 的 `castByLook()`。
> （2026-09-30 核实代码后补注：这条错误曾误导过一次教程审计。）
>

> 全部界面为 Unicode 线框草图，用于确认**信息层级与交互**，不是最终视觉稿。
> 配色沿用 MC 原版 GUI 风格（米黄底 + 深灰边框 + 凹槽），不引入写实风。

**★ 张力反馈以「鱼线颜色」为主，HUD 只做辅助**（已按你的反馈简化）：

| 张力 | **鱼线颜色（主要反馈）** | 鱼线形态 | 音效 | 辅助 HUD（极简） |
|---|---|---|---|---|
| 0–55 | **白** `#FFFFFF` → `#E4E4E4` | 明显下垂弧度（松弛） | 无 | 细条白段 |
| 55–82 | **黄** `#F0C93B` → `#D8A81E` | 轻微下垂 | 线的"嗡"声 | 细条黄段 |
| 82–98 | **红** `#E85C5C` → `#C62828` | 完全绷直 + 轻微抖动 | "吱吱"摩擦声 | 细条红段 |
| ≥98 | **深红闪烁**（2 Hz） | 抖动剧烈 | 高频"吱嘎" | 细条闪烁 |
| 断线 | 线消失 + 水花粒子 | — | 断裂"啪" | — |

**辅助张力条规格（刻意做得极简）**：

| 元素 | 规格 |
|---|---|
| 尺寸 | **260 × 8 px**，屏幕中下方（比原设计更细） |
| 底色 | 白/黄/红三段纯色，**无渐变、无描边光效** |
| 当前位置 | 一根 1 px 深灰竖线 |
| 红区计时 | **只在红区时**出现一条 2 px 深红横线（长度 = 剩余 breakTime） |
| **不做** | ❌ 屏幕暗角 ❌ 画面震动 ❌ 呼吸闪烁 ❌ 额外警告文字（除非玩家在设置里主动开"详细提示"） |

> 默认配置 `tension.hudMinimal = true`、`noScreenShake = true`。玩家想更花哨可以自己在设置里开。

**鱼体力条**：同宽 260 × 6 px，青色填充；体力越低填充越暗。**可以完全关闭**（`hud.showStamina = false`），因为它是辅助信息，不是操作必需。

**挣扎方向指示**：
- 屏幕中央偏下出现大箭头 `◀` / `▶` / `▲`（直冲）
- 箭头颜色：预告阶段半透明 → 生效阶段实心
- Boss 鱼"假动作"：预告箭头闪烁 2 次后突然反向（需要玩家反应）

**操作提示（首次钓鱼时显示，之后可关）**：

```
        ┌──────────────────────────────────────┐
        │ 右键 收线（张力↑）                     │
        │ 左键 放线（张力↓）                     │
        │ A / D 抵消鱼的挣扎方向                 │
        └──────────────────────────────────────┘
```

交互细节：
- 点击槽位 → 弹出该槽位的候选列表（只显示玩家拥有的物品 + 商店可买项，可买项带价格）

- 拆除的部件回背包；背包满则拒绝操作并提示
- 附魔显示在竿身槽位下方；**换竿身会保留附魔，换部件不影响附魔**
- 修理：按缺失耐久比例收费（`每 100 耐久 = 25 鱼币`）

## 8. 完整交互流程（首次游玩引导）

```
① 玩家获得钓竿（合成 或 找老柯领取）
        ↓
② 第一次手持钓竿 → 屏幕右上角弹出教学提示（3 步图文）
   「长按右键蓄力 → 松开抛竿 → 浮漂下沉时提竿」
        ↓
③ 第一次抛竿 → 显示落点预测圈 + 蓄力条绿区高亮
        ↓
④ 第一次咬钩 → 强制显示"！提竿！"大字（后续可关）
        ↓
⑤ 第一次进入张力对抗 → 显示操作提示浮层（右键收线/左键放线/A-D抵消）
        ↓
⑥ 第一次上鱼 → 结算卡片 + 强引导"去找老柯卖掉它"
        ↓
⑦ 到达老柯 → 对话 → 卖鱼 → 获得鱼币 → 打开商店
        ↓
⑧ 教学结束，之后所有提示可通过配置关闭
```
